Install a Display

Flashes the hub firmware onto a board and gives it your WiFi, from this browser, over USB.

  1. Plug the board into this computer with a USB-C data cable.
    3.5" P4 board: use the port marked USB to UART.
  2. Click Install and pick the board's port. The page works out which board it is.
  3. When it asks, enter the WiFi name and password. They go straight to the board over USB and are stored only there.
  4. The display restarts, joins WiFi and appears on the admin page under Devices, ready to name and set up.
This browser can't talk to USB devices. Use Chrome or Edge on a computer. USB access needs a secure page: open this over https (the hub's Tailscale address).

Re-installing a board you already use? Choose not to erase when asked, and it keeps its WiFi. To move a board to another network, click Install, then use Change Wi-Fi from the menu.
